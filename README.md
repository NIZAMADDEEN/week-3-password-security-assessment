## Project Overview

This repository documents my practical cybersecurity exercises completed during **Week 3 of the NetworkWalks Cybersecurity Programme**.

The practical work focused on password security assessment, password hash extraction, and password recovery using two different approaches: John the Ripper and NetworkWalks' browser-based security tools.

The exercises provided practical exposure to password auditing techniques and demonstrated the importance of secure password practices.

## Practical Projects

### 1. W3-PM1 – Password Cracking with John the Ripper

**Tools Used:**
- John the Ripper (JTR)
- Johnny GUI
- Windows environment
- PDF password hash extraction tool

**Activities Performed:**
- Worked with a password-protected PDF in the authorised training environment.
- Extracted and prepared the PDF password hash.
- Used John the Ripper through its graphical interface, Johnny.
- Performed a dictionary-based password recovery exercise.
- Verified the recovered password by opening the protected PDF.

**Key Areas:**
- Password hash analysis
- PDF password protection
- Dictionary-based password auditing
- Password recovery verification

### 2. W3-PM2 – Password Cracking with NetworkWalks Tools

**Tools Used:**
- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker
- Web browser
- Windows environment

**Activities Performed:**
- Worked with the supplied password-protected PDF.
- Used the NetworkWalks Hash Calculator to obtain the PDF password hash.
- Used the NetworkWalks Password Cracker for dictionary-based password recovery.
- Examined the recovery result.
- Verified access to the protected PDF using the recovered password.

**Key Areas:**
- PDF hash extraction
- Hash identification
- Dictionary-based password recovery
- Browser-based security tools
- Password security assessment

## Learning Outcomes

Through these exercises, I strengthened my understanding of how password hashes are extracted and assessed, how dictionary-based password recovery works, and why password complexity is important in protecting digital information.

The two projects also provided an opportunity to work with both locally installed and browser-based password auditing tools.

## Ethical and Security Considerations

These exercises were performed as part of an authorised cybersecurity training programme using designated laboratory materials.

Password auditing and recovery techniques should only be used on files and systems for which appropriate permission has been granted.

Sensitive password hashes, recovered credentials, and private documents should never be published in a public repository.
